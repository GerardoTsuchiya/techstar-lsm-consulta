# Recursos en LSM instalados

Aquí van los archivos (video `.mp4`/`.webm` o imagen `.png`/`.jpg`/`.webp`) de los recursos del catálogo.
La app los carga desde esta carpeta, sin internet (RNF-03).

- Solo recursos del catálogo con procedencia y condiciones de uso registradas. **Nunca** capturas ni grabaciones
  de consultas (RF-18).
- El nombre del archivo debe coincidir exactamente (mayúsculas incluidas) con el campo `archivo` del recurso en
  `catalogo/ficticio-dev.json`. Sin espacios ni acentos; se recomienda el ID de la entrada: `PAC-S-01.mp4`.
- Después de copiar un archivo: `npm run validar-catalogo`.

Paso a paso completo: README del proyecto, sección «Editar el catálogo».
